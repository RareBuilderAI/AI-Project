RobotChat

An autonomous AI assistant ecosystem designed to bridge the gap between static LLMs and functional digital tools.

Python Flask SQLite AI Tool Routing

The Challenge

Standard AI often forgets context or cannot perform real-world tasks. We needed a system that remembers users and executes functions accurately.

The Solution

Implemented a custom ToolRouter architecture and a persistent memory layer, allowing the AI to interact with APIs, databases, and local tools.

The Result

A fully functional assistant capable of managing finances, checking weather, and capturing business leads in real-time.
